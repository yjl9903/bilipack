## 记录要求

- 写明来源链接或核查方式、日期、运行环境、页面或工具版本；无法确定的条件明确标注。
- 分开写观察事实、据此推断的结论和未核查项；“未核查”不等于“不支持”。
- 记录目标值、实际状态、操作接受性和失败原因；结构存在不代表交互已接受。
- 区分本地测试、开发脚本、正式产物及最终保存验证，不能扩大证据范围。
- 页面变化后重新核查，保留必要的前后差异；选择器属于适配实现，不作为产品需求。
- 不保存登录信息、令牌、私人素材或依赖源站 DOM 的自动化 HTML fixtures。
